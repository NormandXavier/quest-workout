# Quest Workout

A personal workout app that issues daily quests computed from real progressive-overload rules.
Installable on iPhone as a Home Screen web app; works offline.

## Commands

- `npm run dev` – local development server
- `npm test` – unit tests
- `npm run build` – production build into `dist/`

## Deploy

Pushing to `main` builds and publishes to GitHub Pages
(repository Settings → Pages → Source: GitHub Actions).
